# Система автоматизации стратегий для нескольких бирж

**Multi-Exchange Strategy Automation System**

## 🎯 Описание проекта

Это корпоративная система автоматизированной торговли криптовалютами для нескольких бирж, **с продвинутой системой арбитража в основе**, обеспечивающая высокопроизводительный и высоконадежный сегментированный арбитраж, сеточную торговлю, торговлю объемами и функции мониторинга рынка. Система использует строгую многоуровневую архитектуру и поддерживает полную адаптацию к нескольким основным биржам, включая Hyperliquid, Backpack, Lighter, Paradex, Binance, OKX, EdgeX, GRVT, Variational и др.

### 🔥 Основные преимущества: продвинутая система арбитража

**Движок арбитража** этой системы является её самым главным и наиболее продвинутым функциональным модулем с следующими уникальными преимуществами:

#### 🚀 Архитектура с двумя режимами
- **Режим сеточного арбитража (сегментированная система)**: использует стратегию сегментированной сетки, постепенно открывает позиции при расширении спреда и закрывает при сужении, снижая рыночное воздействие и потери на проскальзывании. Поддерживает вариант скальпинга (фиксация позиции после триггера ячейки с ожиданием фиксации прибыли) и вариант разделения ордеров (накопление нескольких ордеров в одной ячейке)
- **Режим принятия решений на основе исторических данных**: через непрерывную запись спредов и ставок финансирования пар бирж с помощью рекордера исторических спредов, калькулятор исторических данных вычисляет "естественный спред" (исторический медианный) и "естественную разницу ставок финансирования", движок решений автоматически определяет арбитражные возможности в двух направлениях на основе исторических средних значений и пороговых параметров, установленных пользователем: **арбитраж спреда** (срабатывает, когда текущий спред превышает исторический базовый уровень + порог пользователя) и **арбитраж ставки финансирования** (срабатывает, когда разница ставок финансирования постоянно удовлетворяет условиям)

#### 💡 Единый движок принятия решений
- **Алгоритм, управляемый общим количеством**: `цель - фактическое = дельта`, точный контроль позиций
- **Независимая конфигурация для каждой торговой пары**: независимый риск-контроль, независимые решения для каждой пары
- **Поддержка многоногого арбитража**: поддержка сложных стратегий хеджирования с несколькими ногами
- **Межбиржевой арбитраж**: захват спредов между биржами, максимизация прибыли

#### ⚡ Глубокая оптимизация для Lighter
- **Пакетное размещение ордеров через WebSocket**: `place_market_orders_ws_batch`, сверхбыстрое исполнение
- **Интеллектуальная стратегия дополнительных ордеров**: обнаружение исполнения одной ноги + 3 повторных попытки (REST рыночный → REST рыночный → агрессивный лимитный IOC)
- **Дедупликация push-уведомлений ордеров**: синхронизированный кеш на основе deque+set, точное отслеживание состояния
- **Динамическая защита от проскальзывания**: поддержка динамического проскальзывания от 1x до 100x, адаптация к экстремальным рыночным условиям

#### 🛡️ Многоуровневая система риск-контроля
- **Обнаружение стабильности цен**: фильтрация ложных прорывов, избежание погони за ростом и распродажами
- **Проверка ликвидности встречной стороны**: обеспечение полного исполнения ордеров
- **Интеллектуальное управление Reduce-Only**: автоматическое обнаружение и восстановление, избежание неудачного закрытия позиций
- **Контроллер избежания ошибок**: автоматическая приостановка/возобновление при аномалиях биржи

### Основные функции

- **🏆 Продвинутая система арбитража**: сегментированный арбитраж, многоногий арбитраж, межбиржевой арбитраж, единый движок решений, интеллектуальный механизм дополнительных ордеров
- **📊 Система сеточной торговли**: обычная/мартингейл/подвижная сетка, скальпинг, защита капитала, тейк-профит и стоп-лосс
- **💹 Система торговли объемами**: режим лимитных ордеров (Backpack), режим рыночных ордеров (Lighter)
- **🔔 Система ценовых оповещений**: мониторинг прорывов цен на нескольких биржах, звуковые оповещения
- **🔗 Адаптация к нескольким биржам**: полная адаптация к 9 основным биржам (Hyperliquid, Backpack, Lighter, Paradex, Binance, OKX, EdgeX, GRVT, Variational)
- **🛡️ Интеллектуальный риск-контроль**: многоуровневая система риск-контроля, проверка ликвидности, избежание ошибок, управление reduce-only
- **🎨 UI мониторинга в реальном времени**: современный терминальный интерфейс на основе библиотеки Rich
- **🏗️ Корпоративная архитектура**: многоуровневый дизайн, внедрение зависимостей, разделение интерфейсов, высокая расширяемость

## 🚀 Быстрый старт

### Системные требования

- Python 3.8+ (рекомендуется Python 3.12)
- Поддерживаемые ОС: Linux, macOS, Windows
- Опционально: tmux (для управления несколькими процессами)

### Установка зависимостей

```bash
# Способ 1: зависимости основной среды (арбитраж, бессрочные контракты сетки, торговля объемами)
pip install -r requirements.txt

# Способ 2: зависимости среды Python 3.12
pip install -r requirements-py312.txt

# Способ 3: специализированная среда для Lighter спот (автоматическая установка)
./setup_lighter_spot_env.sh
```

**Описание зависимостей:**
- `requirements.txt` - стандартные пакеты зависимостей
- `requirements-py312.txt` - зависимости, совместимые с Python 3.12
- `requirements-lighter-spot.txt` - специальные зависимости для Lighter спот (новый SDK)
- Подробное описание конфликтов зависимостей: [docs/dependency_conflicts.md](docs/dependency_conflicts.md)

### Настройка API-ключей

Настройте API-ключи соответствующих бирж в директории `config/exchanges/`:

```bash
config/exchanges/
├── hyperliquid_config.yaml   # Конфигурация Hyperliquid
├── backpack_config.yaml       # Конфигурация Backpack
├── lighter_config.yaml        # Конфигурация Lighter
├── binance_config.yaml        # Конфигурация Binance
├── okx_config.yaml            # Конфигурация OKX
├── edgex_config.yaml          # Конфигурация EdgeX
├── paradex_config.yaml        # Конфигурация Paradex
└── grvt_config.yaml           # Конфигурация GRVT
```

### Быстрый запуск различных систем

#### Система сеточной торговли (бессрочные контракты)
```bash
# Активация основной среды
source .venv-py312/bin/activate

# Запуск сеточной торговли
python3 run_grid_trading.py config/grid/lighter-long-perp-btc.yaml
```

#### Система сеточной торговли (Lighter спот)
```bash
# Активация специализированной среды Lighter спот
source .venv-lighter-spot/bin/activate
# Или используйте быстрый скрипт
source activate_lighter_spot.sh

# Запуск сеточной торговли на споте
python3 run_grid_trading.py config/grid/lighter-long-spot-eth.yaml
```

#### Система торговли объемами (режим лимитных ордеров Backpack)
```bash
python3 run_volume_maker.py config/volume_maker/backpack_btc_volume_maker.yaml
```

#### Система торговли объемами (режим рыночных ордеров Lighter)
```bash
python3 run_lighter_volume_maker.py config/volume_maker/lighter_volume_maker.yaml
```

#### Система мониторинга и исполнения арбитража
```bash
# Базовый режим арбитража (решения на основе исторических данных + автоматическое исполнение)
python3 run_arbitrage_monitor.py

# Система арбитража V2 (расширенный мониторинг + исполнение)
python3 run_arbitrage_monitor_v2.py

# Система сегментированного арбитража (режим сетки, рекомендуется)
python3 main_unified.py \
  --config config/arbitrage/arbitrage_segmented.yaml \
  --monitor-config config/arbitrage/monitor_v2.yaml

# Режим только мониторинга (только мониторинг, без исполнения)
python3 main_unified.py \
  --monitor-config config/arbitrage/monitor_lighter_gold.yaml
```

#### Система ценовых оповещений
```bash
python3 run_price_alert.py config/price_alert/binance_alert.yaml
```

#### Сканер волатильности сетки
```bash
python3 grid_volatility_scanner/run_scanner.py
```
